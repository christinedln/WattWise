# WattWise

## Overview
WattWise is a smart IoT-based energy consumption monitoring tool which allows a user to monitor, analyze and manage the energy consumption. Using an ESP32, PZEM-004T energy sensor, Raspberry Pi, and a web application, the system provides remote access to energy usage data, appliance control, and energy insights.

## Features
- Monitoring of voltage, current, power, and energy consumption in real-time
- Remote control of connected electrical outlets through a web application
- Predictive energy consumption forecasting
- Detecting abnormal energy consumption patterns
- Secure cloud-based data storage and visualization
